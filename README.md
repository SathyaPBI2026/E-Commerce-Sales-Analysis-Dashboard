# E-Commerce-Sales-Analysis-Dashboard
Power BI dashboard analyzing e-commerce sales performance, profitability, customer behavior, and regional trends using interactive visualizations, DAX measures, and KPI tracking.

## Project Overview
This Power BI project provides a comprehensive analysis of e-commerce sales performance across different regions, categories, customers, and time periods. The dashboard helps business stakeholders monitor key sales metrics, identify profitable products, analyze customer purchasing behavior, and make data-driven decisions to improve overall business performance.
